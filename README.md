


An AI-powered tool to clean, visualize, and deploy machine learning models from your data in minutes.

## Features
- **AI-Driven Cleaning**: Get smart cleaning suggestions powered by GPT-4o.
- **Natural Language Chatbot**: Ask questions about your data and get insights.
- **Data Enrichment**: Add geolocation data (e.g., latitude/longitude) to addresses.
- **Time Series Forecasting**: Predict future trends in your data.
- **One-Click ML Deployment**: Train a model and deploy a prediction app with a single click.
- **Interactive Visualizations**: Create bar charts, scatter plots, heatmaps, and more.

## Try It
[Live App](https://ai-data-cleaner.streamlit.app)

## How to Use
1. Upload a CSV or Excel file on the "Upload" page.
2. Use the "Clean" page to apply AI-driven cleaning suggestions or manual adjustments.
3. Visualize your data on the "Visualize" page with interactive charts.
4. Train and deploy an ML model with one click.
